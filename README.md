## 🤖 Project 1 — Bottle Sumo | Team: The Dominators

### 🥇 Result: 1st Place — National Competition

A competitive Bottle Sumo robot built with LEGO Spike Prime, designed for fully autonomous decision-making, strategic movement, and real-time opponent detection.

### ✨ Key Features

- **Opponent Detection** — Ultrasonic sensor enables real-time targeting and attack strategy
- **Boundary Detection** — Color sensor keeps the robot within arena limits at all times
- **Autonomous Strategy Logic** — Combines attack, defense, and repositioning algorithms
- **Optimised Build** — Mechanical design tuned for stability, traction, and pushing force

### 🔧 Tech Stack

| Component | Role |
|---|---|
| LEGO Spike Prime | Main robot platform |
| Ultrasonic Sensor | Opponent detection & targeting |
| Color Sensor | Boundary / arena edge detection |
| Python / Scratch | Autonomous strategy programming |

### 👩‍🏫 Mentor Role

- Guided students through full design cycle: build → program → test → optimize
- Mentored development of strategic algorithms for competitive advantage
- Supported sensor calibration and performance tuning for match conditions

## 🌬️ Project 2 — Air Filter Robot | Team: Techno Brick Innovators

### ⭐ Result: Special Achievement Award — RoboFest International, Michigan, USA 🇵🇰

An autonomous air purification robot integrating ground robotics with drone technology — tackling real-world air pollution through a 3-way filtration system and multi-platform wireless communication.

### ✨ Key Features

- **3-Way Filtration** — Mesh pre-filter → activated carbon filter → UV light sterilisation for full-spectrum air purification
- **Ground-to-Drone Communication** — One-way serial pipeline: Arduino (EV3) → ESP32 → CoDrone for synchronized aerial deployment
- **Autonomous Navigation** — LEGO EV3 mobile base for independent positioning and movement
- **Drone-Mounted Filter** — Aerial purification mechanism controlled wirelessly via ESP32
- **Competition-Grade Reliability** — Iterative embedded programming tested across national and international rounds

### 🔧 Tech Stack

| Component | Role |
|---|---|
| LEGO EV3 | Autonomous ground navigation base |
| Arduino | Embedded control on EV3 |
| ESP32 | Wireless serial communication hub |
| CoDrone | Aerial filter deployment |
| UV Light Module | Sterilisation stage |
| Activated Carbon Filter | Chemical filtration stage |
| Mesh Pre-Filter | Particle pre-filtration stage |

### 👩‍🏫 Head Coach Role

- Led the full engineering cycle: concept → design → build → program → test → compete
- Guided system architecture across multi-platform communication (Arduino, ESP32, CoDrone)
- Ran simulation sessions, mock judging rounds, and iterative testing cycles
- Mentored the team through both national (Pakistan) and international (Michigan, USA) competition stages
